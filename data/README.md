# Datos del proyecto

Este directorio está destinado a los datos utilizados en el proyecto de detección de transacciones fraudulentas.

## Conjunto de datos

- **Archivo original:** `dataset_proyecto.csv`
- **Número de registros:** aproximadamente 6,36 millones de transacciones.
- **Número de variables:** 11.
- **Variable objetivo:** `isFraud`, que identifica las transacciones fraudulentas.

## Consideraciones

El conjunto de datos completo se mantiene fuera del repositorio para evitar subir un archivo de gran tamaño. Para reproducir los análisis, se debe disponer del archivo original y colocarlo en este directorio.

# Aplicación de monitorización

Esta carpeta contiene la aplicación de monitorización del proyecto de detección de transacciones fraudulentas.

La aplicación permitirá consultar las métricas de evaluación de los modelos, la prevalencia del fraude y los resultados del análisis retrospectivo de cambios en la distribución de los datos.

La monitorización implementada es retrospectiva y no representa un sistema de monitorización en tiempo real.

# Notebooks de análisis

Esta carpeta contiene los cuadernos de Jupyter desarrollados para el proyecto de detección de transacciones fraudulentas.

- `01_preprocesamiento.ipynb`: preparación y preprocesamiento de los datos.
- `02_entrenamiento.ipynb`: entrenamiento del modelo y optimización de hiperparámetros.
- `03_interpretabilidad.ipynb`: interpretación del modelo e importancia de las variables.
- `04_monitorizacion.ipynb`: evaluación del rendimiento y monitorización del modelo.
